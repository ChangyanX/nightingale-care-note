# P5-T07 — Demo Script and Rehearsal

**Status:** Pending
**Full estimate:** 1 hour
**16-hour path:** 30 minutes
**Dependencies:** Stable demo build and P5-T01 evidence inventory

## Objective

Create a deterministic, timed demonstration that proves the core product story
and trust boundaries without relying on improvisation or unstable external state.

## Required work, in order

1. Write a 5-7 minute script with named accounts and exact seeded patient state.
2. Rehearse Scenario A: under-ten-second Glance orientation and exact AI provenance.
3. Rehearse Scenario B: collaboration, assignment, review, revision comparison, and revert.
4. Rehearse Scenario C: longitudinal manual/AI context and ranking explanation.
5. Include a concise security denial and distinguish seeded from genuine AI evidence.
6. Reset data and verify every step before recording.
7. Record with readable zoom, cursor movement, and narration.
8. Verify the uploaded video anonymously and retain a local fallback.

## Must be done

- No password, token, key, private dashboard, or personal notification is recorded.
- Script avoids any feature that has not passed its release gate.
- Failure/retry fallback is documented for Groq or hosted downtime.
- Demo uses only synthetic identities and content.

## Optional

- Captions and chapter markers.
- Short architecture overlay.

## Acceptance criteria

- [ ] Glance answers what matters, changed, and needs action in under ten seconds.
- [ ] Exact source navigation and review status are visible.
- [ ] Revision/conflict behavior and role ownership are explained.
- [ ] Genuine versus seeded AI behavior is unambiguous.
- [ ] Uploaded link works without unintended account access.

## Done when

The demo reliably communicates product value and evidence within the time limit.
